# GPU / large-memory extras — installed ONLY on a GPU-capable profile
# (`setup_env.sh --profile gpu`), on top of the CPU core in requirements.txt.
#
# Linux + NVIDIA CUDA oriented (the cuml/cudf RAPIDS wheels do NOT run on
# Apple-Silicon/MPS — there the CPU core already covers you; scvi-tools is the exception
# and DOES support MPS). Best-effort, like requirements-extra.txt: setup_env.sh installs
# each constrained by the core pins and skips any that can't satisfy them, so a failed GPU
# wheel never corrupts the working CPU stack. Every script here guards its import and exits
# cleanly with an install hint when the package is absent.
#
# Validated on an NVIDIA RTX 4090 node (CUDA 13 driver) via pip/uv + the NVIDIA index.

# --- reference-model training + scArches query mapping (train_reference_model.py,
#     map_query_scarches.py). scvi-tools bundles scArches surgery + the HuggingFace hub
#     (scvi.hub) for pulling shipped reference models. Supports CUDA and Apple-Silicon MPS.
#     Tested: scVI/scANVI train + scArches surgery run on CUDA end to end.
scvi-tools

# --- GPU k-NN backend for CellMapper (reference_map.py --knn-method rapids), for
#     second-scale label transfer over millions of cells. CellMapper's `rapids` backend
#     calls cuML directly (NOT rapids-singlecell), so cuML+cuDF is all it needs.
#     Resolve via the NVIDIA index: --extra-index-url=https://pypi.nvidia.com
#     Tested: `reference_map.py --knn-method rapids` runs on CUDA with these installed.
cuml-cu12
cudf-cu12

# --- OPTIONAL large-memory zero-shot annotator (run_scimilarity.py). Needs ~64GB RAM and
#     a separately-downloaded model bundle (tens of GB). A foundation model: additional
#     cross-check only, never the primary annotator (see reference/automated_tools.md).
scimilarity

# --- NOT included by default (documented here so the omission is deliberate):
#   * faiss-gpu-cu12 — the community pip wheel is ABI-broken on tested systems
#     (`module 'faiss._swigfaiss' has no attribute 'delete_GpuResourcesVector'`). For a
#     working GPU faiss backend (reference_map.py --knn-method faiss-gpu) install the
#     CONDA `faiss-gpu` build instead. The CPU `faiss-cpu` (in requirements-extra.txt)
#     already gives reference_map.py --knn-method faiss-cpu.
#   * rapids-singlecell — GPU-accelerated scanpy preprocessing. The skill's GPU k-NN does
#     NOT need it (CellMapper uses cuML directly). It additionally requires the full RAPIDS
#     stack + dask (it errors `No module named 'dask'` on a partial install), so install it
#     deliberately only if you want GPU scanpy: `pip install 'rapids-singlecell[rapids12]'`
#     (NVIDIA index) or via conda. The skill annotates pre-existing clusters and does not
#     re-preprocess the main object, so this is a niche win.
